Сочетание концептов №1–№10 · светлые палитры

Свет вместо мрака

Комиссия (ведущий UX/UI-эксперт и профессиональный дизайнер, 15 итераций совещаний) собрала 10 комбинированных решений с учётом функционала страниц и 10 цветовых систем на светлой базе. Основа — концепты №1–№10 из первого борда (design-concepts-10.html).

1 · Протокол комиссии

15 итераций · 3 спринта

Спринт 1 · Матрица совместимости

Итерации 1–5
  1. Матрица 10×10: конфликты — №9 ⇄ №1 (неоморфные тени против чертёжных линий), №7 ⇄ №8 (3D-вес против плакатной лёгкости); синергии — №3+№4, №5+№8, №1+№5.
  2. Концепты поделены на роли: каркас (задаёт «мир»), якорь (несёт функцию), специи (точечно ≤10%). Два каркасных на одной странице = визуальный шум.
  3. Правило доминанты: 1 каркас + 1–2 якоря + ≤1 специя на страницу, не больше.
  4. Страницы сгруппированы в 5 типов: витрина · инструмент · библиотека · лонгрид · транзакция — у каждого свой визуальный «метаболизм» (эмоция / точность / сканируемость / чтение / доверие).
  5. Калькулятор — заповедник: движение только в зоне результата; зона ввода всегда спокойна (ошибка чтения = потеря лида).

Спринт 2 · Сборка сочетаний

Итерации 6–10
  1. Формула 60/30/10: 60% — нейтральный светлый каркас, 30% — якорный концепт, 10% — специи.
  2. Токен-архитектура: концепт = набор CSS-переменных (цвет, радиус, тень, сетка) поверх одной вёрстки. Смена концепта — не переделка.
  3. Роли JS-визуализаций закреплены: №4 — интерактивный ввод, №3 — живой результат, №6 — SEO-диаграммы, №2 — движение в hero после LCP; всё лениво (IntersectionObserver) и уважает prefers-reduced-motion.
  4. Фото-слой обязателен на витрине и в кейсах: эмоцию платим реальными фотографиями установок, а не градиентами.
  5. Итог спринта: 10 рецептов С1–С10 с раскладкой по типам страниц (раздел ниже).

Спринт 3 · Свет вместо мрака

Итерации 11–15
  1. Диагноз тёмного: графит #12161D давит на длинных страницах, фото на нём слепнет, РСЯ-блоки бьют белыми пятнами, оранжевый на чёрном читается «тревожно».
  2. Решение: светлая база (светлота 92–97%), тёмное — «сцены» 8–12% площади: панель результата, графики выработки, футер. Контраст работает как прожектор сцены.
  3. Двух-акцентная система: «солнечный» (янтарь/шафран — CTA, энергия) + «инженерный» (петроль/сталь/синь — данные, ссылки, графики). Один акцент — либо скучно, либо кислотно.
  4. WCAG AA зашит в токены: текст ≥4,5:1, на янтарных кнопках — тёмный текст, РСЯ-контейнеры — нейтральный светлый фон.
  5. Финал: канон = светлая база + чертёжный ритм + солнечный акцент + тёмные сцены данных. Палитры П1–П10 ниже.

2 · Десять сочетаний концептов

с раскладкой по типам страниц
С1

Светлый инженерный каркас

Формула: №10 светлая база + №1 чертёжные штампы + №3 пульт итога + №5 фото в кейсах

Витрина · главная — светлый hero с фото объекта, count-up цифры (№8), полоса фактов
Инструмент · калькулятор — светлые шаги-«бланки», тёмная панель результата-пульт (№3)
Библиотека · справочник — карточки-«спецификации» со штампами ГОСТ (№1)
Истории · кейсы — фото-редакшн (№5): один сильный кадр + смета
Лонгрид · блог — чистая типографика, статичные SVG-диаграммы
Привлекательность 8,5/10 Сложность 1/5 Риск CWV: низкий

Вердикт: Самый быстрый выход из мрака: 60% работы — токены цвета, остальная вёрстка уже есть.

С2

Живой инструмент

Формула: №4 конфигуратор — ядро + №3 пульт + №6 sun-path в шаге ориентации

Витрина · главная — мини-конфигуратор прямо в hero: два слайдера → живая цифра сметы
Инструмент · калькулятор — SVG-дом (№4) меняется на каждом шаге; sun-path (№6) при выборе стороны/угла; результат — пульт (№3)
Библиотека · справочник — спокойные таблицы без движения
Истории · кейсы — пресет «воспроизвести кейс в калькуляторе»
Лонгрид · блог — текст + одна интерактивная диаграмма на статью
Привлекательность 9/10 Сложность 4/5 Риск CWV: INP: rAF-бюджет + мемоизация

Вердикт: Максимум живости там, где принимают решение. Ядро калькулятора в итоговой системе.

С3

Фотореалистичное доверие

Формула: №5 фото-доминанта + №8 плакатные цифры + №3 пульт итога

Витрина · главная — полноэкранный фото-hero, плакатная типографика, count-up окупаемости
Истории · кейсы — журнальные развороты: фото «до/после», смета, отзывы
Инструмент · калькулятор — спокойный светлый — контраст к эмоциональной витрине
Библиотека · справочник — строгая типографика, фото оборудования
Лонгрид · блог — фото-иллюстрации внутри текста
Привлекательность 9/10 Сложность 3/5 Риск CWV: LCP: hero AVIF + fetchpriority

Вердикт: Лучший для лида: реальные установки продают убедительнее графики.

С4

Солнечная наука

Формула: №6 sun-path + годовая heatmap — стержень + №2 потоки в схемах + №10

Витрина · главная — интерактивная heatmap выработки по регионам РФ
Инструмент · калькулятор — шаг региона — мини-карта; шаг ориентации — sun-path (№6)
Лонгрид · блог — SEO-визуализации: «почему 30°», месячная heatmap
Библиотека · справочник — данные с мини-спарклайнами
Истории · кейсы — годовая heatmap объекта в шапке кейса
Привлекательность 8/10 Сложность 3/5 Риск CWV: низкий: SVG легковесны

Вердикт: Лучший для поискового трафика: интерактивные диаграммы собирают внешние ссылки.

С5

Плакат и цифра

Формула: №8 швейцарский плакат — доминанта + №3 + №5 точечно

Витрина · главная — гигантские цифры, модульная сетка, воздух
Инструмент · калькулятор — «бланк» в сетке; результат — плакат из 4 цифр
Библиотека · справочник — таблицы в плакатной сетке
Истории · кейсы — плакатная обложка + фото-галерея внутри
Привлекательность 8,5/10 Сложность 2/5 Риск CWV: минимальный: текст лёгкий

Вердикт: Премиальность без веса — самый CWV-дешёвый способ выглядеть дорого.

С6

Приборная панель

Формула: №9 неоморфные приборы + №3 телеметрия + №4 ввод слайдерами

Витрина · главная — «щитовая» стенда: шкалы автономии и мощности
Инструмент · калькулятор — тумблеры-выборы, шкалы вместо слайдеров, журнал изменений (№3)
Библиотека · справочник — моноширинные таблицы данных
Истории · кейсы — приборное сравнение «было/стало»
Привлекательность 7,5/10 Сложность 3/5 Риск CWV: низкий

Вердикт: Нишевый вкус: техническая ЦА в восторге, массовая настораживается. Неоморфные тени — только крупными элементами.

С7

Документ и производство

Формула: №1 ГОСТ — доминанта + №5 фото объектов + №3 пульт

Все страницы — листы с рамками-штампами, выноски, спецификации
Инструмент · калькулятор — итог = спецификация оборудования на бланке → идеально в PDF
Истории · кейсы — фото с чертёжными выносками и размерами
Витрина · главная — «проектная папка»: обложки листов
Привлекательность 8/10 Сложность 2/5 Риск CWV: низкий

Вердикт: Сильная идентичность для инженеров-заказчиков; на рынке конкурентов с таким языком нет.

С8

Энергия в движении

Формула: №2 частицы/потоки + №4 конфигуратор + №3 пульт

Витрина · главная — canvas-поток энергии в hero (запуск после LCP, пауза вне viewport)
Инструмент · калькулятор — поток-схема результата: панель → инвертор → дом → сеть/АКБ
Лонгрид · блог — анимированные схемы в гайдах
Библиотека · справочник — только статичные схемы
Привлекательность 8,5/10 Сложность 3/5 Риск CWV: CPU/INP: lazy + prefers-reduced-motion

Вердикт: Живость под контролем бюджета: движение — награда, а не фон.

С9

Иммерсивная усадьба

Формула: №7 3D-дом + №4 конфигуратор + №5 фото

Витрина · главная — 3D-усадьба как вход: клик по крыше → солнце, по гаражу → АКБ
Инструмент · калькулятор — 3D-превью конфигурации: панели «ложатся» на крышу
Истории · кейсы — 3D-облёт объекта + фото-галерея
Привлекательность 9/10 Сложность 5/5 Риск CWV: высокий → волна 2, lazy, деградация в SVG

Вердикт: Wow-эффект для презентаций; в прод — только после волн 1–2.

ВЫБОР КОМИССИИ С10

Энергосистема — синтез комиссии

Формула: база №10 · каркас №1+№8 · ядро №4+№3 · доверие №5 · наука №6 · движение №2 · 3D №7 (v2)

Витрина · главная — фото-hero (№5) + плакатные цифры (№8) + региональная heatmap (№6)
Инструмент · калькулятор — живой конфигуратор (№4) + sun-path (№6) в ориентации + пульт-результат (№3) на тёмной «сцене»
Библиотека · справочник — карточки-спецификации (№1), спокойствие
Истории · кейсы — фото-редакшн (№5) + сметы-бланки (№1)
Лонгрид · блог — интерактивные SVG (№6/№2), фото-вставки
Тёмные «сцены» — только результат, графики выработки, футер — 8–12% площади
Привлекательность 9,5/10 Сложность 5/5 Риск CWV: управляемый: тяжёлое — lazy, поэтапно

Вердикт: Рекомендация комиссии: целевая система. Волна 1 = С1 (каркас) → волна 2 = №4+№6 → волна 3 = №2/№7.
