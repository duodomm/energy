# И1: Первый экран и ключевое сообщение

ИНЖЕНЕР:
НАХОДКИ:
1. Hero-блок с акцентом на "независимость" может не резонировать с основной поисковой фразой "солнечные панели для дома цена" — пользователь ищет конкретику, а не концепцию.
2. Упоминание "свой киловатт" может быть непонятно новичку — термины требуют немедленного пояснения в контексте.
3. Калькулятор с 6 шагами может отпугнуть — пользователю, ищущему просто расчёт, не нужно проходить весь визард.
4. LCOE 4-10 ₽/кВт·ч указан без контраста с текущими тарифами — упущена ключевая выгодность.

ПРЕДЛОЖЕНИЯ:
1. Добавить на hero подзаголовок с конкретикой: "Солнечные панели для дома от 80 000 ₽ — расчёт за 2 минуты" / ЗАЧЕМ: Увеличить конверсию с поисковых запросов / КАК: Дополнить существующий hero конкретными цифрами и временем расчёта / УСИЛИЯ: S
2. Создать упрощённый калькулятор "быстрый расчёт" (2-3 поля: регион, мощность, тип дома) / ЗАЧЕМ: Снизить порог входа для тех, кто хочет просто оценить экономию / КАК: Вынести на отдельную кнопку под основным калькулятором / УСИЛИЯ: M
3. В hero-блоке добавить контраст: "Ваша ставка: 19.4 ₽/кВт·ч (дизель) vs 4-10 ₽/кВт·ч (солнце)" / ЗАЧЕМ: Усилить восприятие выгоды / КАК: Визуально выделить сравнение / УСИЛИЯ: S

ЭКОНОМИСТ:
НАХОДКИ:
1. Hero не использует ключевой триггер — "экономия денег", что снижает мотивацию для коммерчески ориентированных пользователей.
2. Не указана окупаемость проекта — основной показатель для принятия решения.
3. Нет социального доказательства в цифрах (например, "10 000 домов уже экономят").
4. LCOE указан без привязки к текущему росту тарифов — упущена долгосрочная выгода.

ПРЕДЛОЖЕНИЯ:
1. Добавить в hero цифру окупаемости: "Окупаемость 3-5 лет — экономьте до 70% на электроэнергии" / ЗАЧЕМ: Увеличить доверие и мотивацию / КАК: Заменить часть текущего текста / УСИЛИЯ: S
2. Включить в hero динамический расчёт экономии для текущего региона (на основе PSH) / ЗАЧЕМ: Сделать предложение персонализированным / КАК: Добавить скрипт определения региона и расчёта / УСИЛИЯ: M
3. Добавить социальное доказательство: "Более 15 000 семей в РФ уже выбрали солнечную энергию" / ЗАЧЕМ: Увеличить доверие к проекту / КАК: Визуально выделить статистику в hero / УСИЛИЯ: S

UX/UI:
НАХОДКИ:
1. Hero-блок содержит два сложных концепта ("независимость" и "свой киловатт") за 5 секунд не усвоить.
2. Нет явного CTA для быстрого расчёта — пользователь теряется.
3. Авто-раскрытие статьи при скролле может раздражать — нарушает ожидания.
4. Путь из 6 шагов в калькуляторе не разбит на этапы — вызывает ощущение сложности.

ПРЕДЛОЖЕНИЯ:
1. Разделить hero на два блока: верхний — конкретное предложение (расчёт цены), нижний — концепция (независимость) / ЗАЧЕМ: Увеличить конверсию за счёт снижения когнитивной нагрузки / КАК: Реорганизовать структуру hero / УСИЛИЯ: M
2. Добавить чёткий CTA "Рассчитать стоимость" с иконкой калькулятора в верхней части hero / ЗАЧЕМ: Снизить потерю пользователей на первом экране / КАК: Выделить кнопку контрастным цветом и размером / УСИЛИЯ: S
3. Сделать авто-раскрытие статьи опциональным (кнопка "читать далее") / ЗАЧЕМ: Увеличить удовлетворённость пользователей / КАК: Заменить авто-раскрытие кнопкой / УСИЛИЯ: S

ДИЗАЙНЕР:
НАХОДКИ:
1. Hero-блок использует кремовый фон (#faf8f3) — снижает контраст и читаемость.
2. Отсутствие визуального элемента, иллюстрирующего солнечные панели или выгоду.
3. Дуотон-фото в hero не передают суть предложения — абстрактность снижает доверие.
4. Цвет CTA (#e8940a) не выделяется достаточно на кремовом фоне.

ПРЕДЛОЖЕНИЯ:
1. Изменить фон hero на тёмный (в рамках "тёмных сцен") с контрастным текстом / ЗАЧЕМ: Увеличить читаемость и выделить ключевое сообщение / КАК: Реализовать тёмный фон hero с сохранением цветовой схемы / УСИЛИЯ: M
2. Добавить в hero реалистичное фото солнечной установки на доме с эффектом "до/после" / ЗАЧЕМ: Увеличить доверие и визуализацию выгоды / КАК: Заменить текущее фото на качественный коллаж / УСИЛИЯ: S
3. Увеличить размер и контраст CTA-кнопки / ЗАЧЕМ: Увеличить кликабельность / КАК: Увеличить padding, сделать жирный шрифт, добавить тень / УСИЛИЯ: S
