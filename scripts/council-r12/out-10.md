# СИНТЕЗ: консолидация и дорожная карта

## ИНЖЕНЕР:
**НАХОДКИ:**
1. Калькулятор требует упрощения для снижения порога входа, но сохранения точности расчётов.
2. Отсутствует сценарный анализ и гибкость параметров расчёта (цены панелей, тарифов).
3. Методология расчёта LCOE и PSH не раскрыта для профессиональной аудитории.
4. Оптимизация мобильной версии критична из-за 70%+ мобильного трафика.

**ПРЕДЛОЖЕНИЯ:**
1. ЧТО: Создать упрощённый калькулятор "быстрый расчёт" (2-3 поля) / ЗАЧЕМ: Увеличить конверсию новичков / КАК: Дополнительный режим в существующий визард / УСИЛИЯ [S]
2. ЧТО: Добавить калькулятор чувствительности к ключевым параметрам / ЗАЧЕМ: Повысить доверие через прозрачность / КАК: Интерактивные слайдеры для цен панелей, тарифов / УСИЛИЯ [M]
3. ЧТО: Разработать раздел с методологией расчёта LCOE / ЗАЧЕМ: Укрепить доверие профессиональной аудитории / КАК: Детальное описание формул и источников данных / УСИЛИЯ [L]

## ЭКОНОМИСТ:
**НАХОДКИ:**
1. LCOE 4-10 ₽/кВт·ч не соотнесён с текущими тарифами (5-7 ₽/кВт·ч) для наглядной выгоды.
2. Отсутствует калькулятор окупаемости и сравнение с дизельным топливом.
3. Нет монетизации бесплатного калькулятора без потери доверия.

**ПРЕДЛОЖЕНИЯ:**
1. ЧТО: Добавить сравнение LCOE с текущими тарифами и дизельным топливом / ЗАЧЕМ: Усилить доказательную базу экономии / КАК: Инфографика с контрастными цифрами на экране результата / УСИЛИЯ [S]
2. ЧТО: Внедрить платную детализацию сметы с контактами поставщиков / ЗАЧЕМ: Монетизация без потери бесплатного функционала / КАК: Кнопка "Скачать детализацию" после расчёта / УСИЛИЯ [S]
3. ЧТО: Создать партнёрскую программу с поставщиками оборудования / ЗАЧЕМ: Дополнительный доход без прямых продаж / КАК: Раздел "Где купить оборудование" с рекомендациями / УСИЛИЯ [M]

## UX/UI:
**НАХОДКИ:**
1. Навигация перегружена для пользователя, ищущего конкретный технический параметр.
2. Пресеты "Дача/Дом/Бизнес" теряют гибкость для нетипичных сценариев.
3. Автосейв работает без индикации прогресса, снижая доверие к процессу.
4. Справочник и глоссарий не интегрированы в статьи.

**ПРЕДЛОЖЕНИЯ:**
1. ЧТО: Создать интерактивную карту России с PSH/СП данными / ЗАЧЕМ: Визуализация региональных различий повысит вовлечённость / КАК: Интегрировать существующие данные в интерактивный компонент / УСИЛИЯ [M]
2. ЧТО: Добавить поле "свой сценарий" в пресеты + подсказки по мощности приборов / ЗАЧЕМ: Увеличить конверсию на шаге 2 / КАК: Интерактивный справочник с мощностью оборудования / УСИЛИЯ [M]
3. ЧТО: Визуализировать автосейв: иконка с прогресс-баром / ЗАЧЕМ: Повысить доверие к процессу / КАК: CSS-анимация статуса сохранения / УСИЛИЯ [S]

## ДИЗАЙНЕР:
**НАХОДКИ:**
1. Hero-блок с акцентом на "независимость" может не резонировать с поисковыми запросами.
2. Визуализации должны соответствовать реальным объектам по конфигурации оборудования.
3. Вес страниц 150-270 КБ критичен для мобильного трафика 70%+.
4. Дуотон-уголки могут упростить восприятие, но важно не перегружать ими разделы с расчётами.

**ПРЕДЛОЖЕНИЯ:**
1. ЧТО: Добавить на hero подзаголовок с конкретикой: "Солнечные панели для дома от 80 000 ₽" / ЗАЧЕМ: Увеличить конверсию с поисковых запросов / КАК: Дополнить существующий hero конкретными цифрами / УСИЛИЯ [S]
2. ЧТО: Оптимизация изображений: сжать до 100 КБ без потери качества / ЗАЧЕМ: Ускорить загрузку на мобильных устройствах / КАК: WebP формат и CDN с адаптивными размерами / УСИЛИЯ [M]
3. ЧТО: Разработать технические гайдлайны для фото-контента / ЗАЧЕМ: Обеспечить точность технических деталей в визуалах / КАК: Чек-лист обязательных элементов для каждого типа объектов / УСИЛИЯ [M]

## ЧТО НЕ ДЕЛАТЬ:
1. Не добавлять тёмную тему (не входит в приоритеты и не востребовано аудиторией).
2. Не усложнять калькулятор дополнительными шагами (сохранять простоту).
3. Не размещать рекламные блоки (подрывает доверие к расчётам).
4. Не добавлять обязательные поля для контактов в калькулятор (сохраняет доверие).

## МЕТРИКИ УСПЕХА через 3 месяца:
1. Увеличение конверсии в калькулятор на 25% (через упрощённый режим и hero с конкретикой).
2. Сокращение времени расчёта до 2 минут (через оптимизацию шагов).
3. Рост времени на сайте на 40% (через интерактивную карту и связанные материалы).
4. Увеличение конверсии в лиды на 15% (через платную детализацию сметы).
