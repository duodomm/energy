# И6: Контент: покрытие семантики и форматы

ИНЖЕНЕР:
НАХОДКИ: 1) Сильные статьи покрывают ключевые технические аспекты, но есть пробелы в практических кейсах по монтажу и обслуживанию; 2) Семантика калькуляторов требует расширения - нет расчёта для систем с ВИЭ+дизель; 3) LCOE расчёт уже есть, но отсутствует калькулятор окупаемости; 4) Нормативка есть, но без комментариев по применению.
ПРЕДЛОЖЕНИЯ: 1) ДОБАВИТЬ калькулятор ВИЭ+дизель / ЗАЧЕМ: охватить удалённые объекты / КАК: добавить шаг выбора генератора, расчёт смешанного режима / УСИЛИЯ [M]; 2) РАЗРАБОТАТЬ калькулятор окупаемости / ЗАЧЕМ: показать экономию за срок службы / КАК: ввести стоимость топлива, рост тарифа, сравнить с сетью / УСИЛИЯ [S]; 3) ДОПОЛИНИТЬ нормативку разделом "Практика применения" / ЗАЧЕМ: снизить количество запросов в поддержку / КАК: добавить комментарии к сложным пунктам / УСИЛИЯ [M].

ЭКОНОМИСТ:
НАХОДКИ: 1) LCOE калькулятора покрывает основные сценарии, но нет расчёта для систем с накоплением; 2) Нет калькулятора сравнения тарифов (сетевая vs автономная); 3) В данных по тарифам нет региональной динамики; 4) Нет калькулятора экономии на пиковых нагрузках.
ПРЕДЛОЖЕНИЯ: 1) РАЗРАБОТАТЬ мини-калькулятор тарифов / ЗАЧЕМ: показать экономию от перехода на автономное питание / КАК: ввести текущий тариф, рост, сравнить с LCOE / УСИЛИЯ [S]; 2) ДОБАВИТЬ калькулятор ёмкости АКБ / ЗАЧЕМ: оптимизировать инвестиции в накопление / КАК: ввести потребление, автономность, глубину разряда / УСИЛИЯ [S]; 3) РАЗРАБОТАть калькулятор кабеля / ЗАЧЕМ: снизить затраты на монтаж / КАК: ввести мощность, расстояние, потери, тип кабеля / УСИЛИЯ [S].

UX/UI:
НАХОДКИ: 1) Статьи без указания даты снижают доверие к актуальности; 2) Нет видео-обзоров калькулятора; 3) Мини-калькуляторы могут повысить конверсию; 4) Нет интерактивных элементов для сложных расчётов.
ПРЕДЛОЖЕНИЯ: 1) ДОБАВИТЬ год в заголовках статей / ЗАЧЕМ: показать актуальность / КАК: автоматическое добавление года при публикации / УСИЛИЯ [S]; 2) РАЗМЕСТИТЬ видео-инструкцию по калькулятору / ЗАЧЕМ: снизить барьер входа / КАК: 1-2 минутное скринкаст-видео / УСИЛИЯ [M]; 3) РАЗМЕСТИТЬ мини-калькуляторы в статьях / ЗАЧЕМ: повысить вовлечённость / КАК: добавить всплывающие виджеты с расчётами / УСИЛИЯ [M].

ДИЗАЙНЕР:
НАХОДКИ: 1) Дуотон-фото хорошо работают, но нет единого стиля для всех разделов; 2) Цветовая схема "Янтарный полдень" узнаваема, но не хватает акцентов для важнейших элементов; 3) Нет 3D-визуализаций для калькулятора; 4) Темные "сцены" используются редко, можно усилить визуальный контраст.
ПРЕДЛОЖЕНИЯ: 1) РАЗРАБОТАТЬ систему 3D-визуализаций / ЗАЧЕМ: повысить вовлечённость / КАК: добавить интерактивные 3D-модели типовых решений / УСИЛИЯ [L]; 2) УТОЧНИТЬ цветовую схему / ЗАЧЕМ: усилить визуальную иерархию / КАК: добавить градации основного цвета, уточнить акценты / УСИЛИЯ [M]; 3) РАЗРАБОТАТЬ инфографику для сложных расчётов / ЗАЧЕМ: упростить восприятие / КАК: создать визуальные схемы для LCOE, окупаемости / УСИЛИЯ [M].
