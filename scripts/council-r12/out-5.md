# И5: Информационная архитектура и перелинковка

ИНЖЕНЕР:
НАХОДКИ: 1) Навигация требует упрощения - текущая структура перегружена для пользователя, ищущего конкретный технический параметр. 2) Справочник и глоссарий не интегрированы в статьи, что снижает полезность контента. 3) Кейсы не связаны с калькулятором - пользователь не может перейти от примера к расчёту для себя. 4) Отсутствие фильтрации по регионам в справочнике снижает релевантность данных для пользователя.
ПРЕДЛОЖЕНИЯ: 1) Создать интерактивную карту России с PSH/СП данными вместо статичной таблицы / ЗАЧЕМ: визуализация региональных различий повысит вовлечённость / КАК: интегрировать существующие данные в интерактивный компонент / УСИЛИЯ [M]. 2) Добавить связанные материалы под статьёй с тегами по темам (типы СЭС, регионы, технологии) / ЗАЧЕМ: увеличит глубину погружения и время на сайте / КАК: создать систему тегирования и автоматической подстановки / УСИЛИЯ [S]. 3) Разработать "умные" хлебные крошки с контекстом предыдущих шагов калькулятора / ЗАЧЕМ: улучшит навигацию в сложном сценарии / КАК: интегрировать с состоянием калькулятора / УСИЛИЯ [M].

ЭКОНОМИСТ:
НАХОДКИ: 1) Статьи не структурированы по воронке принятия решения - от общего к частному. 2) Отсутствие разделения контента по типам объектов (дача/дом/бизнес) снижает релевантность. 3) Кейсы не показывают экономику - только технические характеристики. 4) Нет чёткой связи между контентом и CTA "смета за 24 часа".
ПРЕДЛОЖЕНИЯ: 1) Создать систему "воронки контента": общие статьи → типы объектов → технологии → расчёты / ЗАЧЕМ: приведёт пользователя к цели и повысит конверсию / КАК: перестроить структуру статей с явными переходами / УСИЛИЯ [L]. 2) Добавить калькулятор экономии в каждую статью по теме / ЗАЧЕМ: покажет прямую выгоду от чтения / КАК: создать мини-калькулятор с упрощёнными параметрами / УСИЛИЯ [M]. 3) Разработать карточки "от теории к практике" под статьями / ЗАЧЕМ: соединит знания с действием / КАК: создать шаблонные переходы к калькулятору и кейсам / УСИЛИЯ [S].

UX/UI:
НАХОДКИ: 1) Поиск критически необходим - 14 статей + глоссарий + FAQ создают информационный шум. 2) Related-материалы нужны, но должны быть релевантными текущему контексту (шаг калькулятора/тип объекта). 3) Хлебные крошки обязательны - глубина вложения достигает 3+ уровней. 4) Нет визуального разделения между разными типами контента (статьи/кейсы/справочник).
ПРЕДЛОЖЕНИЯ: 1) Реализовать клиентский поиск с фильтрацией по типу контента и тегам / ЗАЧЕМ: ускорит доступ к нужной информации / КАК: использовать существующие данные из Prisma / УСИЛИЯ [M]. 2) Создать контекстные related-материалы, меняющиеся в зависимости от источника трафика / ЗАЧЕМ: повысит релевантность предложений / КАК: настроить систему рекомендаций на основе поведения / УСИЛИЯ [M]. 3) Разработать визуальную систему разделения контента с использованием цветовых акцентов и иконок / ЗАЧЕМ: улучшит восприятие структуры / КАК: создать гайдлайн для визуального контента / УСИЛИЯ [S].

ДИЗАЙНЕР:
НАХОДКИ: 1) Навигация перегружена визуально - слишком много элементов на странице. 2) Нет визуальной иерархии между разными типами контента. 3) Цветовая схема не подчёркивает важные элементы навигации. 4) Фотографии не систематизированы - разное качество и стиль.
ПРЕДЛОЖЕНИЯ: 1) Создать систему визуальной навигации с использованием цвета и размера / ЗАЧЕМ: упростит ориентацию / КАК: разработать гайдлайн для элементов интерфейса / УСИЛИЯ [S]. 2) Внедрить дуотон-фото для разделов навигации / ЗАЧЕМ: создаст визуальную целостность / КАК: обработать существующие фото по единому шаблону / УСИЛИЯ [M]. 3) Разработать систему иконок для типов контента / ЗАЧЕМ: ускорит распознавание разделов / КАК: создать набор иконок в едином стиле / УСИЛИЯ [S].
