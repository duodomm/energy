# И4: Прозрачность методологии

**ИНЖЕНЕР:**
НАХОДКИ: 
- Методология расчёта LCOE и PSH не раскрыта для пользователя, что вызывает недоверие у профессиональной аудитории.
- Параметры PR=0.78, ставка 10%, рост тарифа 8% — поданы как константы, без объяснения их происхождения и вариативности.
- Нет информации о погрешности расчёта и границах применимости калькулятора для разных климатических зон.

ПРЕДЛОЖЕНИЯ:
- Разработать детальный раздел с методологией расчёта LCOE, включая все формулы и источники допущений (ЧТО / ЗАЧЕМ / КАК / УСИЛИЯ [L]).
- Добавить интерактивный блок с возможностью изменения ключевых параметров (PR, ставка, рост тарифа) с мгновенным пересчётом (ЧТО / ЗАЧЕМ / КАК / УСИЛИЯ [M]).
- Создать карту России с цветовой маркировкой PSH по регионам и ссылками на источники данных (ЧТО / ЗАЧЕМ / КАК / УСИЛИЯ [M]).

**ЭКОНОМИСТ:**
НАХОДКИ:
- LCOE 4-10 ₽/кВт·ч не соотнесён с текущими тарифами и инфляцией, что снижает убедительность расчёта окупаемости.
- Нет объяснения выбора ставки дисконтирования 10% и её влияния на итоговый результат.
- Дизельное топливо (0.27 л/кВт·ч) и газ (0.32 м³/кВт·ч) представлены как эталон, без сравнения с рыночными аналогами.

ПРЕДЛОЖЕНИЯ:
- Добавить в раздел "Как мы считаем" сравнение LCOE с альтернативными источниками энергии в разрезе 20 лет (ЧТО / ЗАЧЕМ / КАК / УСИЛИЯ [S]).
- Включить калькулятор инфляции для роста тарифа и стоимости оборудования (ЧТО / ЗАЧЕМ / КАК / УСИЛИЯ [M]).
- Разработать интерактивный график окупаемости с возможностью изменения начальных инвестиций (ЧТО / ЗАЧЕМ / КАК / УСИЛИЯ [S]).

**UX/UI:**
НАХОДКИ:
- Страница "Как мы считаем" перегружена техническими деталями без иерархии и навигации.
- Нет чёткого CTA после получения результата — пользователь не понимает, что делать дальше.
- Отсутствие возможности сохранить или поделиться расчётом с инженером для верификации.

ПРЕДЛОЖЕНИЯ:
- Реорганизовать страницу в аккордеоны: базовый расчёт → методология → источники → погрешность (ЧТО / ЗАЧЕМ / КАК / УСИЛИЯ [S]).
- Добавить двойной CTA в результат: "Получить детальную смету" и "Проверить с инженером" (ЧТО / ЗАЧЕМ / КАК / УСИЛИЯ [S]).
- Внедрить функцию "Экспорт расчёта в PDF" с полным методологическим обоснованием (ЧТО / ЗАЧЕМ / КАК / УСИЛИЯ [M]).

**ДИЗАЙНЕР:**
НАХОДКИ:
- Техническая страница "Как мы считаем" визуально не соответствует "Янтарному полдню" — слишком много текста, мало визуализации.
- Доверие формируют не только цифры, но и источники — они не представлены визуально.
- Нет иконографической системы для обозначения типов допущений (оценка/факт/расчёт).

ПРЕДЛОЖЕНИЯ:
- Разработать инфографику для ключевых формул LCOE и PSH с цветовой кодировкой переменных (ЧТО / ЗАЧЕМ / КАК / УСИЛИЯ [M]).
- Создать раздел "Наши источники" с логотипами Росстата, NASA и других поставщиков данных в виде "печати доверия" (ЧТО / ЗАЧЕМ / КАК / УСИЛИЯ [S]).
- Разработать систему иконок для обозначения типа информации: факт (галочка), допущение (вопрос), погрешность (диапазон) (ЧТО / ЗАЧЕМ / КАК / УСИЛИЯ [S]).
