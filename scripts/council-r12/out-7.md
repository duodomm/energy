# И7: Визуальный язык и фото-канон

ИНЖЕНЕР:
НАХОДКИ: 
- Дуотон-уголки могут упростить восприятие сложных технических данных, но важно не перегружать ими разделы с расчётами.
- Hero-кадры должны отражать реальные технические решения, а не абстрактные концепции.
- Янтарный акцент хорошо подходит для CTA, но может диссонировать с технической точностью данных.
- Визуализации должны соответствовать реальным объектам по конфигурации оборудования.

ПРЕДЛОЖЕНИЯ:
1. ЧТО: Разработать технические гайдлайны для фото-контента / ЗАЧЕМ: Обеспечить точность технических деталей в визуалах / КАК: Создать чек-лист обязательных элементов для каждого типа объектов (дом/дача/бизнес) / УСИЛИЯ [M].
2. ЧТО: Добавить на hero-кадры элементы инфографики (масштаб, оборудование) / ЗАЧЕМ: Повысить информативность визуалов без текста / КАК: Разработать шаблоны наложения технических элементов / УСИЛИЯ [S].

ЭКОНОМИСТ:
НАХОДКИ:
- Визуальный контент должен отражать экономические выгоды без искажения данных.
- Янтарный акцент может подсознательно ассоциироваться с экономией.
- Hero-кадры должны демонстрировать объекты с разной окупаемостью.
- Дуотон может упростить восприятие сложных экономических показателей.

ПРЕДЛОЖЕНИЯ:
1. ЧТО: Разработать систему цветовой кодировки для экономических показателей / ЗАЧЕМ: Усилить визуальное восприятие выгоды / КАК: Использовать оттенки янтаря для показания экономии по сравнению с тарифами / УСИЛИЯ [M].
2. ЧТО: Создать серию визуалов с LCOE для разных регионов / ЗАЧЕМ: Демонстрировать региональные особенности окупаемости / КАК: Разработать шаблоны наложением данных PSH и тарифов на фото объектов / УСИЛИЯ [S].

UX/UI:
НАХОДКИ:
- Дуотон-уголки могут создавать визуальные якоря для навигации.
- Hero-кадры должны быстро передавать суть предложения без текста.
- Янтарный цвет как CTA-элемент должен быть дозирован.
- Визуализации должны дополнять, а не дублировать живые фото.

ПРЕДЛОЖЕНИЯ:
1. ЧТО: Разработать систему дозировки янтарного акцента / ЗАЧЕМ: Создать иерархию визуального восприятия / КАК: Использовать 10-15% площади для ключевых CTA, остальное — нейтральные фоны / УСИЛИЯ [S].
2. ЧТО: Создать гибридную систему визуалов: фото + элементы 3D-визуализации / ЗАЧЕМ: Объединить достоверность фото с наглядностью схем / КАК: Разработать шаблоны наложения технических элементов на реальные фото / УСИЛИЯ [M].

ДИЗАЙНЕР:
НАХОДКИ:
- Дуотон-уголки могут создать уникальный визуальный язык, но рискуют стать стоковыми.
- Hero-кадры должны соответствовать "янтарному полдню" по цветовой температуре.
- Живые фото должны преобладать над сгенерированными (70/30).
- Визуализации должны сохранять фирменный стиль "янтарного полдня".

ПРЕДЛОЖЕНИЯ:
1. ЧТО: Разработать уникальные дуотон-фильтры с привязкой к регионам / ЗАЧЕМ: Создать узнаваемый визуальный код / КАК: Разработать 5-7 фильтров с учётом климатических зон РФ / УСИЛИЯ [L].
2. ЧТО: Создать гайдлайны по фото-канону / ЗАЧЕМ: Обеспечить качество и уникальность визуалов / КАК: Разработать требования к ракурсам (низкий угол, перспективу), свету (золотой час), времени суток (день/закат) / УСИЛИЯ [M].
3. ЧТО: Разработать систему иерархии визуалов / ЗАЧЕМ: Четко разделять реальные фото и визуализации / КАК: Использовать рамки/тени для сгенерированных кадров, живые фото — без обработок / УСИЛИЯ [S].
