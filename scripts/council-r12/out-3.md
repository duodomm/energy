# И3: Воронка калькулятора: вход и удержание

**ИНЖЕНЕР:**  
**НАХОДКИ**  
1. Вход по пресетам (Дача/Дом/Бизнес) снижает когнитивную нагрузку, но теряет гибкость — пользователи с нетипичными сценариями уходят.  
2. Шаг 2 (приборы) — критическая точка отказа: сложность выбора оборудования + отсутствие подсказок по мощности.  
3. Автосейв работает, но пользователь не видит индикации прогресса — ощущение "работает ли?".  
4. Вход "по счётчику" (кВт·ч/мес) логичен, но требует пояснений: "показания с квитанции" vs "реальное потребление".  

**ПРЕДЛОЖЕНИЯ**  
1. Добавить поле "свой сценарий" в пресеты + подсказки по мощности приборов (микроволновка 1.2 кВт, холодильник 0.2 кВт и т.д.).  
   / Увеличить конверсию на шаге 2 / Сделать интерактивный справочник с мощностью / УСИЛИЯ [M]  
2. Визуализировать автосейв: иконка с прогресс-баром + "сохранено: 15:23" / Повысить доверие к процессу / CSS-анимация / УСИЛИЯ [S]  
3. Шаг 1: две опции — "пресет" и "счётчик" с пояснением "берём среднее за 3 месяца" / Снизить порог входа / Редактирование шаблона / УСИЛИЯ [S]  

**ЭКОНОМИСТ:**  
**НАХОДКИ**  
1. Потеря на шаге 2 — потеря платёжеспособных клиентов (бизнес-сегмент особенно чувствителен к деталям).  
2. Отсутствие контактов в результате снижает конверсию в лиды — пользователь получил расчёт, но не знает "что дальше".  
3. Смета "от–до" без пояснений диапазона вызывает недоверие.  
4. Нет триггеров для возврата — пользователь уходит, но не получает стимула вернуться.  

**ПРЕДЛОЖЕНИЯ**  
1. Шаг 2: добавить кнопку "пропустить и уточнить позже" / Не терять пользователей на ранних этапах / localStorage + email-напоминание / УСИЛИЯ [M]  
2. В результат добавить CTA "получить детальную смету с контактами монтажников" / Увеличить конверсию в лиды / Модальное окно с выбором региона / УСИЛИЯ [S]  
3. В смету пояснить диапазон: "от 350к ₽: базовый комплект; до 1.2M ₽: с резервом и аккумуляторами" / Повысить доверие / Текстовые подсказки / УСИЛИЯ [S]  

**UX/UI:**  
**НАХОДКИ**  
1. 6 шагов — перегруз для новичков; нет прогресс-бара, теряется ориентация "где я?".  
2. Фотополосы пресетов не отражают функционал — пользователь ожидает интерактива, а получает статику.  
3. Нет возврата к предыдущим шагам без перерасчёта — фрустрация при ошибке.  
4. Мобильный стикбар навязчив — закрывает контент.  

**ПРЕДЛОЖЕНИЯ**  
1. Сократить до 4 шагов: 1) объект/потребление 2) генерация 3) накопление 4) вывод / Снизить когнитивную нагрузку / Объединить шаги 1-2 и 4-5 / УСИЛИЯ [L]  
2. Пресеты сделать интерактивными: 3D-конфигуратор с базовыми сценариями / Увеличить вовлечённость / Three.js / УСИЛИЯ [L]  
3. Добавить "шаг назад" с автоматическим обновлением расчёта / Снизить фрустрацию / Логика перерасчёта на изменение / УСИЛИЯ [M]  

**ДИЗАЙНЕР:**  
**НАХОДКИ**  
1. Дуотон-фото в разделах снижает читаемость текста на тёмных "сценах".

3. Нет визуальной иерархии в шагах визарда — все элементы равны.
