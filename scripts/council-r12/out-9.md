# И9: Монетизация без потери доверия

**ИНЖЕНЕР:**
**НАХОДКИ:**
1. Калькулятор генерирует смету без контактов — это сильное доверительное решение.
2. LCOE 4–10 ₽/кВт·ч калькулятора ниже рыночных тарифов 5–7 ₽/кВт·ч — конкурентное преимущество.
3. Автосейв в localStorage повышает конверсию, так как пользователь не теряет данные.

**ПРЕДЛОЖЕНИЯ:**
1. Добавить платную детализацию сметы (ЧТО: опция «Получить полную смету с контактами поставщиков» / ЗАЧЕМ: монетизация без потери бесплатного функционала / КАК: кнопка «Скачать детализацию» после расчета / УСИЛИЯ: S).
2. Внедрить партнёрскую программу с поставщиками оборудования (ЧТО: комиссия за переходы к партнёрам / ЗАЧЕМ: дополнительный доход без прямых продаж / КАК: раздел «Где купить оборудование» с рекомендациями / УСИЛИЯ: M).
3. Создать платный экспертный чек-лист по выбору системы (ЧТО: PDF-гид с расчётами / ЗАЧЕМ: мягкая монетизация полезного контента / КАК: форма подписки после 3-го шага калькулятора / УСИЛИЯ: S).

**ЭКОНОМИСТ:**
**НАХОДКИ:**
1. Закрытие РСЯ снижает трафик, но повышает доверие к ресурсу.
2. Ставка дисконтирования 10% выше рыночных банковских депозитов — это повышает точность расчётов.
3. Рост тарифа 8%/год выше инфляции — оправдано для долгосрочных расчётов.

**ПРЕДЛОЖЕНИЯ:**
1. Ввести платную проверку сметы экспертом (ЧТО: услуга верификации расчёта / ЗАЧЕМ: премиум-монетизация для сложных случаев / КАК: кнопка «Проверить смету экспертом» после расчета / УСИЛИЯ: M).
2. Создать партнёрскую программу с поставщиками (ЧТО: комиссия за продажи через партнёров / ЗАЧЕМ: дополнительный доход без риска / КАК: интеграция с калькулятором, где пользователь выбирает поставщика / УСИЛИЯ: L).
3. Разработать подписку на обновления цен (ЧТО: ежемесячное обновление каталога / ЗАЧЕМ: стабильный доход / КАК: тариф «Про» с доступом к актуальным ценам / УСИЛИЯ: S).

**UX/UI:**
**НАХОДКИ:**
1. Мягкое авто-раскрытие контента без кнопок снижает трение.
2. Отсутствие тёмной темы соответствует бренду «Янтарный полдень».
3. Exit-intent и стикбар повышают конверсию лидов.

**ПРЕДЛОЖЕНИЯ:**
1. Создать мягкий лид-магнит в виде интерактивного чек-листа (ЧТО: PDF-гид с расчётами / ЗАЧЕМ: сбор лидов без агрессивных форм / КАК: всплывающее окно после завершения расчета с предложением скачать чек-лист / УСИЛИЯ: S).
2. Разработать функцию «Сравнить 3 комплекта» (ЧТО: возможность сравнить варианты систем / ЗАЧЕМ: увеличение времени на сайте и конверсии / КАК: кнопка в результатах калькулятора для добавления в сравнение / УСИЛИЯ: M).
3. Внедрить партнёрскую программу с реферальной ссылкой (ЧТО: приглашение друзей / ЗАЧЕМ: виральный рост / КАК: персональная ссылка в профиле пользователя / УСИЛИЯ: S).

**ДИЗАЙНЕР:**
**НАХОДКИ:**
1. Дуотон-фото уголков разделов создают визуальную гармонию.
2. Цветовая схема «Янтарный полдень» (крем, янтарь, петроль) узнаваема.
3. Тёмные «сцены» ≤10% площади не перегружают дизайн.

**ПРЕДЛОЖЕНИЯ:**
1. Разработать премиум-дизайн для платных материалов (ЧТО: визуальное отличие платного контента / ЗАЧЕМ: подчёркивание ценности / КАК: специальная рамка и иконка «Премиум» / УСИЛИЯ: S).
2. Создать визуальный гайд для партнёрской программы (ЧТО: правила использования логотипов / ЗАЧЕМ: поддержание качества бренда / КАК: PDF-документ с примерами / УСИЛИЯ: S).
3. Разработать систему визуальных индикаторов доверия (ЧТО: иконки «Проверено экспертом», «Актуальные цены» / ЗАЧЕМ: повышение доверия к информации / КАК: размещение рядом с ключевыми данными / УСИЛИЯ: S).
