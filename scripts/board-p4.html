«Чертёж.ГОСТ»

Инженерная эстетика рабочего чертежа: миллиметровка, размерные линии, штамп основной надписи, анимация отрисовки «от руки»

Сильный характер
АЛЬТЕРН. ЭНЕРГЕТИКА РФ
СЭС 5 кВт · ДАЧНЫЙ ДОММ 1:100
Лист 1 · Формат А324.09.26
Схема «рисуется» как чертёж — SVG stroke-анимация 2,5 с, потом статика

Палитра

бумагатушьразмеры

Типографика

Заголовки — гротеск (Inter); все технические подписи — моно с табличными цифрами: ГОСТ-вайб в каждой метке

JS / TS

SVG stroke-dashoffset + IntersectionObserver (старт при появлении); в проде — GSAP ScrollTrigger для последовательности блоков

Фото

Не используются — только линия и размер. Фото появляются в контентных блоках поверх чертёжной сетки

Куда в проекте

Гайды и нормативка, PDF-смета (выглядит как настоящий чертёж — сильный триггер доверия для инженеров), шапка статей

Плюсы

  • Уникальный характер — в РФ-нише нет аналогов
  • Почти нулевой CWV-риск: чистый SVG/CSS
  • PDF-смета «как чертёж» = wow в e-mail-рассылке

Минусы

  • Холодный для «дачной» аудитории 50+
  • Не показывает реальные объекты

«Энергопоток»

Тёмная сцена с canvas-частицами: солнце → панели → инвертор → АКБ/дом. Энергия становится видимой — интерфейс «дышит»

Быстрая победа
ПОТОК ЭНЕРГИИ · 3,4 кВт · АКБ 61%
день
заряд АКБ
Частицы идут по траекториям; янтарные — от солнца, бирюзовые — разряд АКБ вечером

Палитра

ночьсолнцегенерацияАКБ

Типографика

Inter для текста; подписи узлов — моно 10–11px, каптион с живыми цифрами

JS / TS

Canvas 2D + requestAnimationFrame; ≤ 120 частиц, shadowBlur только у частиц; пауза вне вьюпорта через IntersectionObserver; вся логика — 150 строк TS

Фото

Нет — генеративная графика нулевого веса (3 КБ кода вместо 300 КБ картинок)

Куда в проекте

Hero главной (слой за заголовком, opacity ≤ 0,5), фон экрана результата, «загрузка расчёта» — частицы собираются в узлы схемы

Плюсы

  • Мгновенная «живость» — лечит главный симптом сухости
  • Объясняет физику: пользователь видит путь энергии в АКБ
  • Ноль ассетов, ноль запросов — LCP не страдает

Минусы

  • Сам по себе доверие не продаёт — нужен фото-слой
  • Держать за текстом, иначе конкурирует с CTA

Экран результата калькулятора (вместо «стены блоков» — KPI-пульт + смета ниже), админ-панель, будущий «Мониторинг» для реальных клиентов

Плюсы

  • Двухтарифная логика становится наглядной

Минусы

  • Тёмный пульт не для посадочных и статей — читать текст тяжело
