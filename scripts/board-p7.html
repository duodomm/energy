Вердикт комиссии: гибридная стратегия

итог итерации 20

Комиссия единогласно отклонила «выбор одного концепта»: продуктовая задача (инженерный инструмент + контент + лидогенерация) шире любой одной эстетики. Рекомендуется система с ролями: каждый концепт получает зону ответственности в продукте.

Итоговая формула оформления

ЯДРО ОПЫТА : №4 Живой конфигуратор (визард) + №3 Центр управления (экран результата)

ДВИЖЕНИЕ  : №2 Частицы в hero + №8 count-up итогов + drawing-анимации графиков ECharts

  • 3D-усадьба (№7) по кнопке, Three.js lazy

Как читать этот документ. Каждая секция выше — работающее демо на чистом JS (canvas/SVG/CSS), без внешних библиотек: демо можно открыть офлайн, код переносится в Next.js как компоненты. Оценки в метрах — консенсус комиссии по шкале 0–100. Фотоматериалы в демо №5 — реальные изображения из поиска (для продакшена нужны лицензированные или собственные съёмки). Бюджет производительности (LCP ≤ 2,5 с · INP < 200 мс · CLS ≤ 0,1) заложен в каждую концепцию: анимации только на transform/opacity, частицы ≤ 120 с паузой вне вьюпорта, 3D — lazy по клику, фото — AVIF/WebP + lazy + фиксированный aspect-ratio.
