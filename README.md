# Альтернативная энергетика РФ

Инженерный калькулятор и справочник по автономному энергоснабжению:
солнечные станции, накопители, резервная генерация и экономика собственных
киловатт. Все расчёты выполняются на клиенте; сайт выкладывается на
Cloudflare (Static Assets + Workers) в free tier.

## Что внутри

- **Калькулятор СЭС (6 шагов)** — нагрузка, регион (32 региона РФ с PSH и
  тарифами), панели/инвертор, накопитель с прибором автономии, генерация,
  результат со сметой. PDF-смета оформлена как лист конструкторского
  документа (рамка и основная надпись по мотивам ГОСТ 2.104).
- **3D-усадьба** — самописный canvas-рендер (~7 КБ, без Three.js):
  панели растут от мощности, зима/лето, тени, вращение мышью.
- **Интерактивная карта России** — проекция Альберса, контур Natural Earth,
  маркеры регионов с зумом по округам.
- **Демонстрация физики** — canvas-частицы энергопотока
  СОЛНЦЕ → ПАНЕЛИ → ИНВЕРТОР → АКБ → ДОМ с дневным/ночным циклом.
- **Хабы-статьи** (Солнечная энергетика, Накопители, Генерация, Экономика),
  кейсы, глоссарий, FAQ, справочник регионов — контент в SQLite (Prisma),
  при статической сборке выгружается в `public/api-data/*.json`.
- **Лид-контур** — Worker на Cloudflare: honeypot, Turnstile, запись в D1
  (без персональных данных), уведомление в Telegram.

## Стек

Next.js 16 (App Router) · TypeScript · Tailwind CSS · shadcn/ui ·
Prisma 6 + SQLite · Cloudflare Workers / D1 / R2 · Яндекс.Метрика

## Быстрый старт

```bash
bun install            # или npm install
bunx prisma generate   # генерация клиента (БД уже в комплекте: db/custom.db)
bun run dev            # http://localhost:3000
```

SQLite-файл с контентом лежит в `db/custom.db` (путь в `prisma/schema.prisma`
относительный — репозиторий переносим). Пересобрать данные из исходников:
`bunx prisma db push && bunx tsx prisma/seed.ts`.

## Структура

| Путь | Назначение |
|---|---|
| `src/app/` | роуты и API Next.js |
| `src/components/pages/` | страницы (главная, калькулятор, хабы, кейсы…) |
| `src/components/calc/` | визард расчёта, смета ГОСТ, схема станции |
| `src/components/common/` | карта РФ, 3D-усадьба, энергопоток, уголки страниц |
| `src/lib/calc/` | ядро расчёта: solar, engine, constants, months |
| `prisma/` | схема БД и данные для сидинга (`prisma/data/*.ts`) |
| `worker/` | Cloudflare Worker лид-контура + schema.sql (D1) |
| `scripts/` | сборка статики, выгрузка БД в JSON, пайплайн карты |
| `public/api-data/` | JSON-бандл контента для статического режима |

## Сборка и деплой на Cloudflare

```bash
bash scripts/build-static.sh   # дамп БД → JSON, next export → out/
npx wrangler deploy            # Static Assets + Worker (wrangler.json)
```

Подробная инструкция (секреты, лимиты free tier, обновление контента) —
в [`DEPLOY-CLOUDFLARE.md`](DEPLOY-CLOUDFLARE.md).

## Производительность

LCP ≤ 2,5 с · INP ≤ 200 мс · CLS ≤ 0,1: все анимации на rAF с паузой вне
вьюпорта и поддержкой `prefers-reduced-motion`; канвы фиксированной высоты;
фото оптимизированы (PIL) и грузятся lazy с фиксированным aspect-ratio.
